## Callable behavior and limits

`worldgen::NoiseGenerator::builtin(seed, settings)` constructs the actual seeded
router and independent positional owners for the seven pinned settings.
`fill_noise(chunk_x, chunk_z, level_min_y, level_height, FreshGenerationContext)`
performs source-ordered interpolation, aquifer/ore/default-material selection,
WG heightmap updates and ordered fluid postprocessing. It returns owned
`NoiseTerrain` borrowing the generator and carrying `TerrainStage::Noise`.
`build_surface(&mut terrain, &mut SurfaceContext)` stages actual rules, clay
bands and badlands/iceberg extensions; success advances only to `Surface`.

`DensityRouter`, `RandomStateRandoms`, `NoiseChunk`, `Aquifer`/`AquiferContext`
and `SurfaceSystem`/`SurfaceHost` expose the supporting source-backed owners.
The detailed [API and Main contract](../../reference/world-generation-integration.md)
documents signatures, ownership and observable order.

Caller facts must establish initially empty block data, empty Blender and empty
structure beardifier. Present/unknown influences, partial custom noise cells,
empty vertical overlap, custom settings/fluids and unavailable biome/thermal
owners are explicit unsupported errors. The implementation never supplies a
flat fallback or returns a FULL chunk. Natural multi-biome selection, carving,
features, structures, lighting, final conversion, persistence and runtime chunk
publication are not implemented by this delivery.
