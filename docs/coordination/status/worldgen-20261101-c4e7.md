## Callable behavior and supported boundaries

`NoiseGenerator::builtin(seed, settings)` constructs the seeded router and
independent positional owners for the seven pinned built-in noise settings.
`fill_from_noise(chunk_x, chunk_z, level_min_y, level_height, context)` returns
`NoiseFillOutcome::{Generated,NoCells}`. `NoCells` carries exact clamped metadata
and no image/status; the caller retains the SAME existing input ProtoChunk.
Positive generation performs actual source-ordered interpolation, aquifer/ore/
default-material selection, WG heightmaps and ordered fluid-postprocessing output.

`fill_noise(...)` retains its stricter positive aligned-cell API.
`build_surface(&mut terrain, &mut SurfaceContext)` applies actual rules, bands,
badlands and iceberg extensions privately; success advances only to `Surface`.
`NoiseTerrain` borrows its generator and retains the same graph/cache identity
through both phases. Supporting owners include `DensityRouter`,
`RandomStateRandoms`, `NoiseChunk`, `Aquifer`/`AquiferContext` and
`SurfaceSystem`/`SurfaceHost`.

Positive generation requires actual owner observations of initially empty block
data, empty Blender and empty structure beardifier. Positive partial custom
cells, custom settings/fluids, nonempty blending/structure influence and missing
biome/thermal owners remain explicit unsupported boundaries. Natural multi-biome
selection, carving/features/structures, lighting, final FULL conversion,
persistence, readiness and production publication are not implemented by this
source handoff. No flat fallback or fabricated completed chunk is provided.
