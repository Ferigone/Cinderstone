## Concrete implementation and API

`attribute_transfer::{assign_base_values, assign_all_values}` accept the actual target/source AttributeMap handles plus the existing `AttributeMapHost`. No additional actor/supplier/world owner is fabricated. Errors distinguish real host failure from source live traversal failure. Source and target can be the same retained instance: full self-copy intentionally clears all modifier indexes but preserves base/definition/object identity.

Both transfers use a position-only live fastutil values.forEach cursor: capture initial `n`; for every next step reread the current table. There is no captured count, no sorted keys or copied source map. A newly inserted lower slot can be visited. Target getInstance runs before assignBase rereads source base, retaining source object even across target allocation and nested dirty callbacks. Full copy reuses source replacement data including actual shared modifier Arc identity and per-operation map behavior. Actual synchronous map dirty listener runs only after all source mutations, with every map/instance borrow released; errors preserve the completed prefix.

`attribute_persistence` provides native `ResourceLocation` immutable value + exact ASCII namespace/path and first-colon/default-namespace parsing, `ModifierFieldError`, borrowed `AttributeWarning`, `AttributePersistenceHost`, and `AttributePersistenceError`. Public callable bodies are `load_modifier`, `save_modifier`, `load_instance`, `save_instance`, `load_map`, `save_map`, using the actual existing `crate::nbt::{JavaString,Tag}`. No invented DTO codec or compiled attribute ID fallback.

The host extends existing AttributeMapHost with mandatory actual bound holder-name lookup (`unwrapKey` may be None), actual global ATTRIBUTE registry resolution, pure immutable ResourceLocation modifier-key/name bridges, and the real warning sink. A new holder or Java identity hash must never be allocated merely to satisfy these methods. Existing actual map/supplier/retained object ownership remains required. Modifier name bridges are pure value operations: source record codecs introduce no gameplay callback and this permits retaining an immutable permanent-record snapshot for encoding.

Source state phases:

1. Modifier fixed record codec requires id, amount, operation; uncompressed NbtOps requires operation serialized strings `add_value`, `add_multiplied_base`, `add_multiplied_total`. All six numeric tags convert to double; strings/numeric IDs/numeric operations reject. Unknown keys are ignored. Malformed record issues are delivered once to the real warning owner, then source skip. Failed warning returns its failure without subsequent mutations.
2. Existing raw Float/Double negative zero is preserved by LOAD. SAVE double factories normalize signed zero to positive zero. NaN remains valid. This distinction was corrected and explicitly checked against the independent unchanged-original probe.
3. Instance load first writes raw `base` (all numeric tags; missing/wrong type→0), preserving old dirty flag and cached value. It never clears indexes. It iterates compound modifier entries; a wrong nonempty list element type yields no records. Every valid record creates a new real modifier object and stores byID→operation bucket→permanent. Duplicate ID replaces the byID/permanent entry but leaves old-operation ghosts, existing other transient/permanent records and index insertion history. Only after the whole loop does one actual dirty callback occur. Warning failure can leave changed raw base and old clean cache; terminal dirty failure leaves completed records and map dirty insertion.
4. Instance save requires a truly bound holder before writing id/base. It emits raw base, only permanent records in original ArrayMap encounter order, omits modifiers when permanent set empty, and does not evaluate/clamp the value cache. Loaded foreign attribute id is ignored by Instance.load; save still uses receiver's actual bound holder id.
5. Map load handles each compound record in original list order: raw string id→ResourceLocation.tryParse→actual ATTRIBUTE registry lookup→actual per-actor getInstance→Instance.load. Malformed/unknown warnings have their actual original raw/name payloads. A registered holder absent from the actual supplier is silently skipped, without invented instance/definition allocation. Missing/wrong id reads empty string, which is valid `minecraft:` and normally produces unknown-registry warning.
6. Map save uses the distinct captured-count live values iterator: additions do not extend its initial remaining count. Each next step rereads current arrays and preserves source shrink/missing-wrapped failure behavior. Empty ListTag has element type END; nonempty saved list uses COMPOUND.

Narrow existing helpers are callback-free field fragments only, and do not change existing public methods. Helpers stage exact fields before existing real AttributeMap dirty listener; no callback is invoked while either an instance or map borrow is held. Native retained Rc/RefCell fixture asserts every host entry can obtain all mutable borrows, so tests would fail if implementation held a borrow across callback.
