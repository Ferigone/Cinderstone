# Stan zgodności z Minecraft Java 1.21

Cel to natywna implementacja zachowania dokładnie **1.21**, protokół **767**, DataVersion **3953**, ze zwykłym klientem Java. Pełna zgodność nie została osiągnięta. Wynik testu potwierdza wyłącznie wymieniony zakres.

Bieżący kod roboczy i jego granice opisuje [CURRENT_WORK.md](CURRENT_WORK.md).
Poniższe wyniki zachowują historyczny zakres; nie potwierdzają automatycznie późniejszych zmian.

Wzorzec: server SHA-1 `450698d1863ab5180c25d7c804ef0fe6369dd1ba`, inner JAR SHA-256 `8d47de9a76ab47186deba6c9beda6f9345c6f73618fa5a157c57608be0505a01`. Java służy jako oracle; proces serwera Rust jej nie uruchamia.

Dowody i odtwarzalne narzędzia znajdują się w `evidence/` i `tools/`. Liczby opisują wektory lub operacje konkretnego testu, nie procent pokrycia gry. Zaliczenie obecnych testów nie oznacza pełnego 1:1. Nowe mechaniki wymagają porównania z niezmienionym JAR-em i integracji z normalnym klientem.

Serwer nadal działa w kreatywnym scenariuszu testowym. Ma stały spawn i nie realizuje pełnej ochrony ruchu ani reguł survival. Brakujące pakiety nie mają jeszcze wszystkich handlerów. Deadline, liczba graczy i bufory nie są pełną kopią polityki vanilla.
